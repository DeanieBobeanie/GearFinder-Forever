# Data sources

Checked October 3, 2026.

- [Forever Codex item database](https://forever-codex.com/items/) supplies item stats, class masks, effects, quest reward records and crafting records extracted from the Forever client. The bundled build is 1.60.1.70205.
- [Gear snapshot](https://forever-codex.com/data/gear/items.json) includes its field layout. The importer reads item source records from `/data/items/c/`, the quest index from `/data/quests/list.json`, and Classic source and quest records from `/data/classicdb/` on that same site.
- [Forever Codex dungeon list](https://forever-codex.com/dungeons/) supplies recommended level ranges. These are not entrance-level guarantees.
- [Forever Codex Hall of Thanes coverage](https://forever-codex.com/dungeons/the-hall-of-thanes/) explains why its item data lacks new dungeon drop tables.
- [cMaNGOS classic-db](https://github.com/cmangos/classic-db/tree/ec4f596146be6467ea93c57397858e329e2db852) is the origin of Classic drop and quest data. Forever Codex converts those records to JSON. Gear Finder converts a subset to Lua and marks Classic routes. Its dungeon importer retains named drops and, where spawn locations are absent, uses the source index's recorded boss and dungeon name. It excludes raids and general world drops.
- [AtlasLoot Forever 1.1.7](https://www.curseforge.com/wow/addons/atlasloot-forever/files/9032996) was checked as an alternative. Its new dungeon loot remains pending. Gear Finder does not bundle or require AtlasLoot.
- [Blizzard UI source mirror](https://github.com/Gethe/wow-ui-source) provides API reference context. The runtime checks API availability before requesting item data or comparisons.
- The mirror's [Forever chat utilities](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_ChatFrameBase/Shared/ChatFrameUtil.lua) and [chat editor](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_ChatFrameBase/Shared/ChatFrameEditBox.lua) provide the reference for opening a party-chat draft and inserting a link.
- The [Forever Inspect UI source](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_InspectUI/Camelot/Blizzard_InspectUI.lua), checked October 5, 2026, provides the reference for `CanInspect`, `NotifyInspect`, matching `INSPECT_READY` to the unit GUID, and reading inventory links. Inspection identifies equipped items; acquisition sources still come from the bundled snapshot.
- The [Inspect equipment layout](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_InspectUI/Camelot/InspectPaperDollFrame.xml) and [equipment click handler](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_InspectUI/Mainline/InspectPaperDollFrame.lua) provide the reference for the native Inspect button integration. Gear Finder uses `HookScript` on each equipment button's `OnClick` script and reads `InspectFrame.unit`. XML assigns function references to the buttons before the add-on attaches, so hooking only the global function misses those clicks.

The owner requested faction farming preferences in `FarmingRules.lua`. Ragefire Chasm routes appear only for Horde. Ruins of Lordaeron routes appear only for Alliance. These preferences also cover recorded related quest rewards. Users can disable them with the Use faction farming preferences checkbox. They do not establish entrance restrictions. [Wowhead's Ruins of Lordaeron walkthrough](https://www.wowhead.com/forever/news/the-ruins-of-lordaeron-new-dungeon-walkthrough-for-wow-forever-383021) lists quests for both factions. The Horde exclusion is the owner's explicit preference.

The importer preserves original source notices in CLASSICDB-NOTICE.md, CLASSICDB-LICENSE.md, CLASSICDB-COPYRIGHT.md and CLASSICDB-AUTHORS.txt. The Classic records carry GPL-3.0 terms. The original Gear Finder code is available under GPL-3.0-or-later. The GPL text is included in CLASSICDB-LICENSE.md. World of Warcraft game content remains the property of its respective owners.

The generated Data.lua is editable source. `snapshot-manifest.json` records hashes of downloaded JSON inputs. `tools/build_gear.py` in the project records the conversion logic and can reproduce or refresh the data. The source repository includes that importer under `tools/build_gear.py`. The installable ZIP contains only the add-on and its documentation.
